# Mapesa Tours & Accommodations

A mobile-first Next.js application and installable PWA foundation.

## Stack
- Next.js App Router
- TypeScript
- Custom responsive CSS
- Web App Manifest
- Service worker with offline fallback
- Vercel deployment

## Run locally
Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy
Push this repository to GitHub, import it into Vercel, and deploy using the default Next.js settings.

## PWA
The manifest is generated by `app/manifest.ts`. App icons are in `public/icons/`. The service worker is registered by `app/components/register-sw.tsx`.

This is the Phase 1 foundation. Booking, customer accounts, admin tools, database connections and payment processing are not yet implemented.
